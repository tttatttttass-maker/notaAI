# ✦ Nota AI — заметки с бесплатным AI (Groq)

Учебное веб-приложение: Markdown-таблицы, чек-листы, папки, теги, дедлайны и **настоящий AI через бесплатный тариф GroqCloud**. AI предлагает изменения, а пользователь решает, применять ли их.

## 1. Как включить бесплатную нейросеть

1. Перейди на **https://console.groq.com/keys** и зарегистрируйся.
2. Нажми **Create API Key** и скопируй секретный ключ `gsk_...`.
3. Убедись, что установлен **Node.js 18+**: https://nodejs.org/
4. В папке `Nota_AI` скопируй `.env.example` в новый файл `.env` (важно: не `.env.txt`).
5. Открой `.env` обычным Блокнотом и впиши ключ:

   ```ini
   GROQ_API_KEY=gsk_сюда_твой_ключ
   GROQ_MODEL=openai/gpt-oss-20b
   PORT=3000
   ```

6. Открой терминал **в папке Nota_AI** и запусти:

   ```bash
   node server.js
   ```

7. Открой **http://localhost:3000** в браузере. Внизу справа появится `AI подключён · Groq API`.
8. Введи: `Создай заметку План подготовки к экзамену с таблицей, чек-листом и дедлайном на 30 ноября` и нажми **Применить** после проверки предложений.

Важно: двойной щелчок по `index.html` запускает **только локальный деморежим**. Для настоящего Groq всегда запускай `node server.js` и открывай `localhost:3000`.

## 2. Бесплатно ли это?

У GroqCloud есть бесплатный тариф с лимитами запросов и токенов; для него **не нужен баланс OpenAI**. Подключение к платному тарифу необязательно. Актуальные лимиты: https://console.groq.com/docs/rate-limits

Рекомендуемая модель: `openai/gpt-oss-20b`. Несмотря на часть имени `openai`, она предоставляется через **Groq**, а не платный OpenAI API.

## 3. Запуск вообще без API

Можно просто открыть `index.html` — заметки, Markdown, чек-листы, дедлайны, экспорт и базовые демокоманды будут работать без интернета. Но это не настоящая нейросеть.

## 4. Структура проекта

- `index.html` — интерфейс.
- `styles.css` — стили и адаптация к телефону.
- `app.js` — заметки, Markdown, локальный деморежим и подтверждение AI-изменений.
- `server.js` — простой сервер Node.js, который безопасно передаёт запросы в Groq API.
- `.env.example` — пример настройки ключа.
- `ОТЧЁТ_Nota_AI.docx` — отчёт для защиты.
- `screenshots/` — примеры интерфейса.

## 5. Инструкция

1. Продемонстрируй создание заметки и Markdown-таблицы.
2. Введи команду: `Разложи мои заметки по папкам и добавь подходящие теги`.
3. Покажи **список действий**, который AI предлагает перед сохранением.
4. Примени действия кнопкой **Применить**.
5. Объясни, что API — это способ связать своё приложение с готовой нейросетью, без её обучения с нуля.

## 6. Важно о данных и безопасности

- **Не пересылай `.env` и ключ другим людям**, не загружай его в GitHub: `.gitignore` исключает `.env`.
- Заметки хранятся локально в `localStorage` браузера; используй «Экспорт» для резервной копии.
- При отправке команды настоящему AI на сервер Groq передаётся текст команды и часть содержимого заметок, чтобы AI мог их организовать. Не отправляй в него конфиденциальные сведения.
- Изменения не применяются без подтверждения пользователя.
- Бесплатные лимиты могут изменяться. При их превышении будет ошибка, а заметки останутся нетронутыми.
- Для API нужна сеть; сервер не публикуется в интернете автоматически.

Документация: https://console.groq.com/docs/openai и https://console.groq.com/docs/structured-outputs
